# Convenciones de la LLM Wiki

- Leer primero `wiki/index.md` y verificar los hechos contra las fuentes curadas o el código.
- Usar páginas Markdown por tema y enlaces relativos/Obsidian cuando ayuden a navegar.
- Clasificar cada contenido durable: **HECHO**, **DECISIÓN**, **PREFERENCIA** o **PREGUNTA ABIERTA**.
- Actualizar `wiki/index.md` ante páginas nuevas y agregar un evento breve, cronológico y append-only a `wiki/log.md`.
- No persistir conversaciones completas, secretos, tokens, passwords, credenciales ni PII.
- No cambiar el estado de una HU sin la aprobación o evidencia exigida por la documentación Scrum.
